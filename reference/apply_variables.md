# Declare a complete variables category and restructure the frame to match

Declare a complete variables category and restructure the frame to match

## Usage

``` r
apply_variables(data, variables, strict = TRUE)
```

## Arguments

- data:

  An aniframe.

- variables:

  The complete variables category.

- strict:

  Whether an invalid axis role errors rather than degrading the
  coordinate system to `unknown`.

## Value

`data`, restructured and re-declared.
