# Warn when coordinate_system no longer matches variables_where

Assumes
[`ensure_is_spatial()`](https://animovement.dev/anicore/reference/ensure_is_spatial.md)
has already passed.

## Usage

``` r
warn_coordinate_system_drift(data)
```

## Arguments

- data:

  An anipoint object.

## Value

`TRUE`, invisibly.
