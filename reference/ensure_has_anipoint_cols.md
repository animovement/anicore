# Validate required columns for anipoint

Validate required columns for anipoint

## Usage

``` r
ensure_has_anipoint_cols(
  data,
  variables_what,
  variables_when,
  variables_where,
  index = "time"
)
```

## Arguments

- data:

  Data frame to validate.

- variables_what:

  Identity variables.

- variables_when:

  Temporal variables.

- variables_where:

  Spatial variables.
