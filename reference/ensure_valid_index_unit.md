# Ensure a unit for the index is a level of unit_time

Ensure a unit for the index is a level of unit_time

## Usage

``` r
ensure_valid_index_unit(unit, call = rlang::caller_env())
```

## Arguments

- unit:

  The proposed unit, or `NULL`.

- call:

  The caller's environment, for the error.

## Value

`TRUE`, invisibly.
