# Drop rows of an aniframe with missing values

Drop rows of an aniframe with missing values

## Usage

``` r
# S3 method for class 'aniframe'
drop_na(data, ...)
```

## Arguments

- data:

  An aniframe.

- ...:

  Columns to look in, passed to
  [`tidyr::drop_na()`](https://tidyr.tidyverse.org/reference/drop_na.html).

## Value

An aniframe.
