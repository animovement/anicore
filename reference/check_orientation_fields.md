# Validate the orientation fields being written, and keep handedness in step

Validate the orientation fields being written, and keep handedness in
step

## Usage

``` r
check_orientation_fields(data, md, user_md)
```

## Arguments

- data:

  The frame being written to.

- md:

  The metadata about to be written.

- user_md:

  The fields the caller supplied.

## Value

`md`.
