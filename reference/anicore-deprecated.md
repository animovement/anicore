# Deprecated aniframe constructors

The position-grain frame is now called `anipoint`; `aniframe` names the
abstract parent class shared with
[anievent](https://animovement.dev/anicore/reference/is_anievent.md).
These aliases forward to their replacements.

## Usage

``` r
aniframe(...)

as_aniframe(data, ...)

example_aniframe(...)

validate_aniframe(data)
```

## Arguments

- ...:

  Passed to the replacement function.

- data:

  Passed to the replacement function.

## Value

The replacement function's value.
