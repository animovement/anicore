# Restructure an anievent

Like
[`restructure_anipoint()`](https://animovement.dev/anicore/reference/restructure_anipoint.md),
but never grouped.

## Usage

``` r
restructure_anievent(data, variables_what, variables_when)
```

## Arguments

- data:

  An anievent object.

- variables_what, variables_when:

  The declaration to apply.

## Value

`data`, restructured, with the declaration recorded.
