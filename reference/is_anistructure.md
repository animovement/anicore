# Test whether an object is an anistructure

Test whether an object is an anistructure

## Usage

``` r
is_anistructure(x)

ensure_is_anistructure(x)
```

## Arguments

- x:

  An object.

## Value

`is_anistructure()`: logical. `ensure_is_anistructure()`: errors if not.

## Examples

``` r
is_anistructure(example_structure())
#> [1] TRUE
```
