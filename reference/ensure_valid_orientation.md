# Check a `where$orientation` declaration against the frame

Check a `where$orientation` declaration against the frame

## Usage

``` r
ensure_valid_orientation(data, orientation, coordinate_system)
```

## Arguments

- data:

  A plain data frame holding the columns.

- orientation:

  Named character vector, role to column.

- coordinate_system:

  The frame's coordinate system.

## Value

`TRUE`, invisibly.
