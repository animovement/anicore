# An example structure for the keypoints of [`example_anipoint()`](https://animovement.dev/anicore/reference/example_anipoint.md)

A spine from `abdomen` to `neck`, a head, shoulders, and two legs with
knee joints. Limits are illustrative, not anatomical.

## Usage

``` r
example_structure()
```

## Value

An `anistructure`.

## Examples

``` r
example_structure()
```
